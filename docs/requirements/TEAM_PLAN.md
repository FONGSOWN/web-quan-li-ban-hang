# Gợi ý chia việc cho nhóm

- Thành viên 1 — Phân tích & tài liệu: SRS, use case, quy trình nghiệp vụ, biên bản họp.
- Thành viên 2 — Frontend: layout, sản phẩm, khách hàng, đơn hàng, dashboard.
- Thành viên 3 — Backend: API, xác thực, validation, phân quyền, xử lý lỗi.
- Thành viên 4 — Database & QA: schema, migration, seed, test case, kiểm thử tích hợp.
- Nếu nhóm ít người, gộp vai trò nhưng vẫn cần review chéo.

## Quy trình Git
1. Tạo issue rõ tiêu chí chấp nhận.
2. Branch `feature/<ten-chuc-nang>`.
3. Commit nhỏ, mô tả hành động.
4. Pull request kèm ảnh/test result.
5. Một thành viên khác review trước khi merge.
